# Django TF-IDF Analyzer

Веб-приложение на Django, которое позволяет загрузить текстовый файл (`.txt`) или документ Word (`.docx`) и получить таблицу из 50 наиболее "информативных" слов на основе показателей **TF (Term Frequency)** и **IDF (Inverse Document Frequency)**.

## Возможности

- Загрузка текстовых файлов `.txt` и `.docx`
- Поддержка английского и русского языков
- Подсчёт TF и IDF для слов, сортировка по убыванию IDF
- Отображение результатов в виде таблицы
